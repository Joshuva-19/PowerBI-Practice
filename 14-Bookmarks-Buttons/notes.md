\# Bookmarks, Buttons \& Interactive Navigation



\## Topics Practiced



\- Power BI bookmarks

\- Power BI buttons

\- Bookmark actions

\- Interactive report navigation

\- Switching between report views

\- Improving dashboard usability



\## Practice



Created bookmarks to save different report views and used buttons to navigate between those views.



Created an Overview view for the main dashboard and a Category Analysis view for focused category-level analysis.



Buttons were configured with bookmark actions to allow users to switch between the report views.



\## What I Learned



Bookmarks can save the current state of a Power BI report page, including visual visibility, filters, and slicer selections.



Buttons can be used with actions such as bookmarks to create interactive navigation within a report.



Combining bookmarks and buttons can make a Power BI report easier to navigate and more interactive.



\## Business Use



Bookmarks and buttons can help users move between different analytical views without creating multiple separate reports.



They can also improve dashboard usability by providing simple navigation between overview and detailed analysis.
