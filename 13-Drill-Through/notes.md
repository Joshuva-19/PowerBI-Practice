\## Drill-Through Page



Created a Product Details page that provides detailed information for a selected product.



The page includes:



\- Total Sales

\- Total Profit

\- Total Orders

\- Sales Trend

\- Product Details Table



\## What I Learned



Drill-through allows users to move from a summary report to a detailed page based on a selected data point.



The selected value is passed as a filter to the drill-through page, allowing detailed analysis of the selected item.



A Back button can be used to return to the previous report page and improve report navigation.



\## Business Use



Drill-through can help users investigate individual products, customers, regions, or other business dimensions without overcrowding the main dashboard.
